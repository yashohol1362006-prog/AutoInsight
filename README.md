# 📊 AutoInsight

AutoInsight is a Business Analytics Dashboard built using Python, Pandas, Matplotlib, Seaborn and Streamlit.

## Features

- Upload Sales CSV
- Automatic Business Insights
- Revenue Analysis
- Interactive Charts
- Seaborn Visualizations

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit

## How to Run

pip install -r requirements.txt

streamlit run app.py
